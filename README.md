Resumo do projeto realizado:

Levando em conta as observações e exigências, decidi realizar o teste da seguinte maneira...
Cumprindo as exigências de uso de API para consulta e atualização de dados, criei a página com um pequeno formulário, possuindo apenas um único campo. Este campo contém um limite de 7 números, para padronizar a pesquisa dos boletos cadastrados. Apenas números são aceitos neste campo do formulário e a tentativa de inserir qualquer outro tipo de caractere será barrado pelo próprio formulário.

A princípio, a seção que exibe os resultados de busca está oculta pelo JavaScript e permanecerá desta forma até que um resultado seja encontrado.
Optei por um design minimalista, mas funcional. Visando praticidade e fácil compreensão.
